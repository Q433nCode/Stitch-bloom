🧶 Stitch & Bloom

Handmade crochet clothing, made to order with love — one stitch at a time.


Stitch & Bloom is a modern e-commerce website designed for a handmade crochet clothing studio. The platform allows customers to browse crochet products, choose colours and sizes, save their favourite items, request custom pieces, and place orders through WhatsApp.

The website focuses on creating a warm, simple and user-friendly shopping experience while showcasing the uniqueness of handmade crochet products.

🌸 Live Website

Visit the website:

✨ Features
🛍️ Product Collection

Customers can browse a collection of handmade crochet clothing, including:

Tops
Skirts
Dresses
Hats
Made-to-order crochet pieces

Products can be filtered by category to make browsing easier.

🎨 Product Customisation

Customers can select options such as:

Wool colour
Size
Quantity

This allows customers to personalise their selected crochet piece before adding it to their shopping bag.

❤️ Favourites

Customers can save products they like to their Favourites list.

This provides an easy way to return to products they may want to purchase later.

🛒 Shopping Bag

The website includes a shopping bag where customers can:

View selected products
Change quantities
Select delivery options
Add order notes
View the total
Submit an order
📱 WhatsApp Ordering

Orders can be sent directly through WhatsApp.

The customer provides:

Name
WhatsApp number
Delivery preference
Optional notes

The order can then be submitted through WhatsApp, making communication between the customer and the crochet studio simple and direct.

💭 Custom Quote Requests

Customers can request a custom crochet item if they cannot find exactly what they want in the collection.

The custom quote form allows customers to provide:

Name
WhatsApp number
Type of item
Preferred wool colours
Budget range
Measurements
Additional design details

This makes the website suitable for personalised and made-to-order crochet work.

🧶 About Section

The website includes a studio story explaining the handmade nature of the business and its focus on creating colourful crochet clothing without mass production.

📞 Contact

Customers can contact Stitch & Bloom through:

WhatsApp
Email
Direct website interaction

The website is presented as a South African-based crochet studio.

⚙️ Admin / Order View

The website includes an administrative/demo view for viewing:

Orders
Quote requests

The current implementation stores this information in the browser's local storage. Therefore, it is intended as a lightweight/demo implementation rather than a production multi-user administration system.

The main goals of Stitch & Bloom are to:

📌 Current Limitations

The current version is primarily a frontend/demo implementation.

Some features that would require a production backend include:

Secure user authentication
Multi-device order synchronisation
Persistent database storage
Secure admin management
Real-time inventory
Online payment processing
Production-level order management

The website itself currently notes that its admin/order view reads from browser storage rather than a secure multi-device backend.
